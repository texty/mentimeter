## Структура даних
У папці вже є файли як приклад.

- Щоб обробка даних відбувалась правильно, файли всередині `static/data/raw/` мають мати таку наступну структуру, до прикладу:
1. Спочатку назва папки `Вінницька область/` - це назва області до якої відноситься анкета. Якщо її немає, можна використовувати будь-яку іншу назву, до прикладу `Курс «Бізнес»`, просто вона не відображатиметься на мапі.
2. Далі в ній має знаходитись сам файл з анкетами `Глуховецький ліцей (Хмільницький район).xlsx` Спочатку назва закладу і обов'язоково назва району в дужках.
**ВАЖЛИВО!** Назви районів мають відповідати реформі 2020 року, інакше їх просто не буде на мапі.
