## Структура файлів

У папці вже є файли як приклад.

Щоб обробка даних відбувалась правильно, файли всередині `static/data/raw/` мають мати наступну структуру:

1. **Папка області**: `Вінницька область/` - назва області до якої відноситься анкета. Якщо її немає, можна використовувати будь-яку іншу назву (наприклад `Курс «Бізнес»`), але вона не відображатиметься на мапі.

2. **Файл з анкетами**: `Глуховецький ліцей (Хмільницький район).xlsx` - спочатку назва закладу, потім обов'язково назва району в дужках.

> **ВАЖЛИВО!** Назви районів мають відповідати реформі 2020 року, інакше їх не буде на мапі.
